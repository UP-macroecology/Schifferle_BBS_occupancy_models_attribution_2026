nyears <- length(unique(route_sel_env_dt_final$Year)) # 25

# species presences:

presences_spec <- bbs_dt_occ %>% 
  select(c(English_Common_Name, RTENO, Year, paste0("Count", seq(10, 50, 10)))) %>% 
  filter(English_Common_Name == spec)

# match to routes-year-env:

occ_dt_spec <- route_sel_env_dt_scaled %>% 
  # add observations:
  collapse::join(presences_spec, on = c("RTENO", "Year"), how = "left") %>% 
  # if route was surveyed but species not observed, replace NA with 0:
  mutate(across(Count10:Count50, ~ 
                  case_when(Surveyed == 1 & is.na(.) ~ 0,
                            .default = .))) %>%
  # convert bird counts to presence / absence:
  mutate(across(Count10:Count50, ~ 
                  case_when(. > 1 ~ 1,
                            .default = .)))

# reformat obs. as array sites x surveys x years (same as for JAGS):

To change priors we use the brms implementation. Brms includes two shrinkage/ regularization priors, horseshoe and R2D2.

  • horseshoe:

    • “Horseshoe prior is symmetric around zero with fat tails and an infinitely large spike at zero. This makes it ideal for sparse models that have many regression coefficients, although only a minority of them is non-zero.”

    • uses two levels of regularization, global and local, the global parameter τ pulls all the weights globally towards zero, while the thick half-Cauchy tails for the local scales λj allow some of the weights to escape the shrinkage

    • brms arguments (regularized horseshoe):

      • df (default 1): Degrees of freedom of student-t prior of the local shrinkage parameters

      • scale_global (default 1): Scale of the student-t prior of the global shrinkage parameter; determines how much shrinkage is applied, Piironen and Vehtari (2017) recommend to specifying the ratio of the expected number of non-zero coefficients to the expected number of zero coefficients `par_ratio` rather than `scale_global` directly

      • df_global (default 1): Degrees of freedom of student-t prior of the global shrinkage parameter

      • scale_slab (default = 2): scale of student-t-slab (regularization, only affects non-zero coeff., expected value of the non-zero coefficient?)

      • df_slab (default = 4): df of the student-t-slab (regularization, only affects non-zero coeff.)

      • par_ratio: Ratio of the expected number of non-zero coefficients to the expected number of zero coefficients; specified, scale_global is ignored and internally computed as par_ratio / sqrt(N), N is the total number of observations in the data

For now, I defined par_ratio instead of scale_global. I assumed that roughly 1/4 of the coefficients may be non-zero -> par_ratio = (1/4)/(3/4) = 0.33. This results in a scale_global of 0.3/sqrt(11900) = 0.003 (default is 1). Not sure about this.

What does this mean?

https://mc-stan.org/loo/reference/loo-glossary.html

  • elpd = theoretically expected log pointwise predictive density for a new dataset, can be estimated using cross-validation

  • elpd_loo = The Bayesian LOO estimate of out-of-sample predictive fit

    • predictive density given the data without the iths data point/series, log transformed and summed over all data points/series

  • p_loo = difference between elpd_loo and non-cross-validated log posterior predictive density, how much more difficult is it to predict future data compared to observed data

    • can be interpreted as effective number of parameters, if everything is fine: p_loo < N and p_loo < p (=total number of parameters)

      • warning: Some Pareto k diagnostic values are too high. See help(‘pareto-k-diagnostic’) for details:

  • looic = -2*elpd_loo

  • Pareto k diagnostic estimates how far an individual leave-one-out distribution is from the full distribution

    • diagnostic threshold for Pareto k depends on sample size S, loo package uses the nominal sample size S when computing the sample size specific threshold

    • Pareto k is also useful as a measure of influence of an observation. Highly influential observations have high k values.
